Solaris Bay — an original sun-soaked coastal open-world crime game built in pure ES modules and 2.5D perspective HTML5 Canvas, featuring 4 districts, 7 drivable vehicles, 5-star police chases, on-foot & drive-by combat, a 5-mission story arc, procedural Web Audio, save/load, and a live minimap HUD.

## Run it

```sh
node serve.ts
```
